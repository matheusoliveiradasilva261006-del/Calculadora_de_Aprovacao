# 👨‍💻Calculadora de Aprovação

Projeto desenvolvido em Java para calcular a média, a frequência e a situação de aprovação de um aluno.\

> Feito por Matheus Oliveira aluno da FATEC Americana

## Sobre o projeto

### O programa solicita:

-> Nome do aluno  
-> RA  
-> Disciplina  
-> Quantidade de aulas  
-> Quantidade de faltas  
-> Duas notas  

Com essas informações, o programa calcula a média e a frequência do aluno e informa se ele está aprovado, em recuperação ou reprovado.

### Regras:

* Média ≥ 7,0 e frequência ≥ 75% → Aprovado

* Média ≥ 5,0 e frequência ≥ 75% → Recuperação

* Demais situações → Reprovado
